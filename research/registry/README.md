# Research registry

| File | Purpose |
|---|---|
| `00_master_methodology.md` | Hard rules, and methods that survived validation. Anything else is a hypothesis and lives in the roadmap. |
| `01_roadmap.md` | The programme roadmap. Start every session here. |
| `experiment_registry.md` | Every experiment, newest first: pre-registration, then verdict. |
| `method_graveyard.md` | Rejected approaches and why. An entry is added only after a REJECT verdict. |
| `feature_evidence.md` | Per narrative feature: mechanism, evidence, scope, confidence. |
| `changelog.md` | What changed, why, and on what evidence. Newest first. |

## Verdicts

- **ACCEPT**
- **ACCEPT WITH SCOPE LIMIT**: the scope is recorded with the verdict.
- **MONITOR**
- **REJECT**: the method goes to the graveyard.

## The loop

Hypothesis, pre-registration (committed), simplest baseline, run, slice analysis, counterexample
search, verdict. Do not stop after one good result. Gates are numeric and stated in advance.
Overriding a gate needs a recorded rationale, not a silent exception.
